# game-toolkit

Rules kept after looking on GitHub, for the agent that makes games in this account.

Before inventing a system, read `cards/`. If nothing covers the job, search GitHub, keep the best licensed solution as a new card, and push it here. A card is the decision. The link is the code.

The standing rule is `SKILL.md`. It is also installed at `~/.grok/skills/game-github-toolkit`.

Already on this account, and not recopied here:

- [rpg-campaign-maker](https://github.com/luaproxy1993/rpg-campaign-maker) — one sitting from a campaign slice or a book
- [world-bible](https://github.com/luaproxy1993/world-bible) — the world the campaigns sit on
- [world-bible-pack](https://github.com/luaproxy1993/world-bible-pack) — portraits, map, places, props

## Cards

- [dialogue](cards/dialogue.md) — Ink, Yarn Spinner, or the small graph we already run
- [genre shape](cards/genre-shape.md) — one primary paradigm, primitives stay in their own skills
