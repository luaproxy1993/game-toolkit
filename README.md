# game-toolkit

Rules kept after looking on GitHub, for the agent that makes games in this account.

Before inventing a system, read `cards/`. If nothing covers the job, search GitHub, keep the best licensed solution as a new card, and push it here. A card is the decision. The link is the code.

The standing rule is `SKILL.md`. It is also installed at `~/.grok/skills/game-github-toolkit`.

Already on this account, and not recopied here:

- [rpg-campaign-maker](https://github.com/luaproxy1993/rpg-campaign-maker) — one sitting from a campaign slice or a book
- [world-bible](https://github.com/luaproxy1993/world-bible) — the world the campaigns sit on
- [world-bible-pack](https://github.com/luaproxy1993/world-bible-pack) — portraits, map, places, props
- [my-game-design-director](https://github.com/luaproxy1993/my-game-design-director) — this author's scene, quest, and play judgments

## One sentence to production

A path from one sentence to a narrative world at Barovia production quality (not Barovia content). Sixteen skills, in eight steps. The count does not include Godot engine-module skills.

Three skills already have their own repos and are not recopied here: [rpg-campaign-maker](https://github.com/luaproxy1993/rpg-campaign-maker), [world-bible](https://github.com/luaproxy1993/world-bible) (`core-rule-book`), and [world-bible-pack](https://github.com/luaproxy1993/world-bible-pack).

The other twelve live in [`skills/`](skills/). See the [pipeline card](cards/one-sentence-pipeline.md) for which skill fires in which step.

`one-sentence-conductor` is not written yet. Do not use `game-maker-pipeline` as a stand-in.
