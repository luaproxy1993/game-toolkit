# Game GitHub toolkit

The toolkit is https://github.com/luaproxy1993/game-toolkit. The local checkout is `/Users/a123/grokmaker/game-toolkit`. If that directory is missing, clone the repo there. Cards in `cards/` are the decisions. Upstream stays at its own URL.

## Steps

1. Read `cards/`. If a card covers this job, follow that card. The research step is done when the work uses the card's rule.
2. If no card covers it, search GitHub. Keep a solution that is maintained, has a clear license, and already does the job. Prefer a tool used in released games, or a skill whose rule is more specific than its star count.
3. Add one card: source URL, license, the rule to keep, and what not to copy or migrate. Commit it and push to `main`.
4. A card is the decision. Do not vendor upstream source into this repo.
5. A campaign lock stays in that campaign. A card does not restate one game's speeches, flags, or endings.

Done when an existing card was the rule you followed, or the new card is on `main`.
