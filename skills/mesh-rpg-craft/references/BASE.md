# D · 底层

## D1 世界书

文本箱：`/core-rule-book`。本战役只 excerpt 入口脸、切片起止、西路是否封、气质句。不在战役会话里重写整本世界。

## D2 硬节点

写在战役 `docs/NODES.md`（或 pack 的 quest/event 表），不是本 skill 目录。一行一拍：

```text
id | 房间 | 必经? | 进入 flag/knowledge | 离开效果 | 谁在场 | 下一拍
```

主线是一条必经链（例如：酒馆恳求 → 宅邸守灵 → 教堂守夜 → 墓地 → 鞠躬 → TBC）。  
支线从节点上挂入口，不另开世界。  
演绎（CG/战斗）挂在节点的 action 上，不挂在「导演心情」。

没有这张表就写 NPC，等于让静帧台词当主线。

## D3 GUI 数值

- HP、轮次、技能、立场条：只读 `player` / `npc_conflict` / `flags`。  
- 文案随拍变（护棺、驱狼），键位数量固定，避免堆叠。  
- 职业五键：四基础 + 本职业一技能；主键一条金，不把全表技能画出来。  
- 数值浮动来自检定与效果，不来自立绘或 intro。
