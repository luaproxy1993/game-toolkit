# 踩坑（一场 Doki 魔改吸血鬼村切片）

观感来自立绘、背景、UI 同一套元素。网状任务来自 NPC+节点把玩家往下推。两套都是一环扣一环。GitHub 技能能省生成；Doki 接线、拍门控、通道、本地包不能省。

## 美术：单点心血来潮

| 踩坑 | 正确 |
|------|------|
| 每来一个想法就单独调教一轮（闪光、粒子、出场、loop） | 先锁主外观和 master still，特效是叠层 |
| 立绘带场景、带光晕、带粒子烤进 PNG | RGBA 主体干净；FX 运行时叠 |
| 白底不干净 / 绿幕残留进对话 | 键色验收；chroma 只给 intro 视频 |
| intro 画幅、人物比例和静帧不一致 | intro 从静帧 i2v，同一画布 |
| 三版失败门破片叠成一条正片 | 三选一，作者点名后再 concat；旧失败片不进 live |
| 场景 loop 狼冲过道把棺材冲没 | 机位锁、主体清单（棺必须在） |
| 找不到 Doki 引擎就在战役根新写 walk/look/talk 页 | 停手去取 DokiDemo 壳，不要用纸壳顶替 |
| 把失败/未对齐板当下一稿参考 | 从上一张已接受的锁重切，闸过再 remount |
| LOOK 已改，live pack 仍挂旧锚（如水彩留下） | 同一趟装新锚并退役旧锚 |
| 创建页背景用看板娘的 `object-position: 42%` | 场景 cover+center；角色展示与场景轮播隔离 |
| 创建页套 CharacterActor / aura / Live2D | 只有 opt-in 的房间静帧轮播；立绘仍是卡片 |
| UI 堆叠：姓名+轴+导演四行，或全职业技能金条重叠 | 一行头；战斗五键；条件文案人话 |

## NPC / 导演：有状态、无认知

标志位进了 context pack **不等于** NPC 知道当前拍。

| 踩坑 | 正确 |
|------|------|
| `npc.dialogue` 永远当「开口就说」 | 当前拍 `opening_line`，旧稿 `conditions` 关掉 |
| `dialogue` 表整表倒进人格 | `evaluateConditions` 过滤 |
| 导演 talk 动作 `conditions: {all: []}` | 与拍绑定；坟边换墓地稿 |
| 行踪只判断「埋了/没埋」，棺在教堂/墓地仍说侧厅 | 按 coffin_at_* / room 写一行事实 |
| 「不要说他还躺在侧厅」写进 known_text | 直接写现在在哪；测试用正向事实，避免负句误伤 |
| 兜底问答硬编码宅邸 | 兜底读 location / quest node |
| 导演有 knowledge 仍输给静帧人设 | 人格锚点必须换拍，不能只靠 flags 列表 |

## 流程：举步维艰的来源

- 改开口才发现 intro 比例不对，回头重渲，再把 NPC 卡冲掉。  
- 作者门用感觉不用清单，于是永远「再来三张」。  
- 想并行，但 intro 依赖静帧、台词依赖节点，没有锁文件。  
- 低完成度版本仍可玩：切的是村子+葬礼，不是全模组。不满意时审计当前层，不把切片扩成城堡。

## 交付

- 本地试玩必须 HTTP：双击启动器，不要 `file://`。  
- Mac 包用 `.app` / `.command`；第一次 Gatekeeper 要 Control-打开。  
- 对话密钥只进本机 `director.env`，不进对外 zip 说明里的「随便传」。
