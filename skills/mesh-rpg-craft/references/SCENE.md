# B · 场景轨

静帧生成跟 `game-asset-core`。动起来跟 `game-animation-frames`（video-first）。数字人背景 still plate 跟 `pixverse-r1` `SEED_VIDEO.md`。

## B1 场景静帧

- 原生画幅：场景板是场景板，地图是地图，禁止把 1:1 油画塞进 16:9 槽。  
- 与立绘同一主外观（光、色、介质）。  
- 完成：硬刷新后进房看到的就是这张；旅行缩略图另出，不拿地图冒充。

## B2 idle loop

- 从 B1 静帧 i2v：机位锁、微动（旗、烛、雾、布），首尾可接。  
- 主体清单写进 prompt（棺、门、祭坛），验收时逐项还在。  
- 创建页背景轮播只用**房间静帧**，3s 交叉淡入淡出；opt-in；不碰 CharacterActor。  
- 完成：loop 两圈无跳；关视频时静帧仍是那张。

## 空间关系验收（窗稿）

- 生成前把窗稿里的左右、前后、门洞与相邻房间关系写成主体清单，出图后对照验收。
- 安全改图（透视换位、局部重绘）仍可能把相邻空间画反；验收不过就整张重来，不要用带血迹/血腥的参考图绕过策略。
- 不要为了「修一张」推翻已 accept 的 M0 外观锁。
