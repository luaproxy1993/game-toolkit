# 锁序：为什么不能一口气并行

网状战役里每一层都吃上一层的产物。并行只允许在**同一把锁已经接受之后**的兄弟轨。

## 锁

| 锁 | 解锁什么 | 没锁时并行会怎样 |
|----|----------|------------------|
| 主外观 | 所有图、所有视频、UI 色 | 每张图各调一次，token 烧在风格漂移上 |
| 立绘静帧 RGBA | intro、粒子、对话立绘 | intro 比例漂、alpha 破、粒子烤进脸 |
| 场景静帧 | idle loop、创建页背景、旅行板 | loop 丢棺材/换机位；背景和立绘两套世界 |
| 硬节点 + flag | NPC 卡、导演候选、GUI | 坟边仍念侧厅；导演「有标志位」但开口是旧拍 |
| 拍门控卡 | 导演、行踪、兜底问答 | 合法动作仍是「考利安何时入土」 |
| 导演只读当前包 | 小游戏、CG 触发 | 导演现场编节点或重开已封的路 |

## 可并行（M0 接受之后）

```
        M0 主外观
       /          \
  立绘轨 M1–M3    场景轨 M4–M5
       \          /
        M6 节点（可与美术后半重叠，若节点表不依赖具体像素）
              |
         M7 NPC 卡
              |
         M8 导演
              |
         M9 GUI 数值
```

故事轨与美术轨交叉点：CG / intro 的**构图**必须引用已接受静帧。节点表不写像素路径也可以先写；一旦 CG 开拍，构图以静帧为准。

## 禁止当「优化」的回头

- 为了 intro 好看重画一张不成套的立绘  
- 把三版失败 i2v concat 成正片等作者挑  
- 用「不要说侧厅」当人格，却仍把侧厅稿注入开口  
- 战斗 HUD、对话栏、创建页背景互相抄角色展示（看板娘 42% 构图、chroma intro、aura）  
- 未过作者门就开下一层，靠下一层掩盖这一层的脏 alpha / 旧认知  

## 沉淀

并行的前提是锁文件存在且 `accepted` 含该步。没有锁，就还在串行。把锁写成短文件（路径 + 一句气质 + 画幅 + 键规则），下一会话才能真的分轨。
