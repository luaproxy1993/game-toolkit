# PixVerse R1：人话版对接说明

> 给产品 / 运营 / 半技术同学。工程师细节见 `VERIFIED_API.md` 与 `AGORA_PROTOCOL.md`。

## 这是什么？

不是「点一下等 30 秒出一个短视频」。

更像：**连进一个正在直播的 AI 世界**——画面一直在生成，你用文字指挥「接下来发生什么」。

| 普通文生视频 | R1 实时 |
|--------------|---------|
| 提交 → 等待 → 下载 MP4 | 进房 → 一直播 → 中途改剧情 |
| 固定长度一条 | 预约时间窗内连续生成 |
| 只和 HTTP 打交道 | HTTP 排队开门，**画面走 Agora** |

## 生活比喻：包 AI 摄影棚

| 步骤 | 人话 | 技术名 |
|------|------|--------|
| ① 选布景 | 官方世界观或自己写世界设定 | scenario / world preset |
| ② 预约棚时 | 占名额（独占或排队） | reservation |
| ③ 查预约 | 到点了吗？排第几？ | reservation query |
| ④ 进棚 | 拿直播间钥匙 | session → Agora |
| ⑤ 开机 | 告诉系统开始推画面 | `init_message` |
| ⑥ 导播 | 「突然下雨」「角色转头」 | `prompt_message` |
| ⑦ 收工 | 关会话；有时能下整段录像 | close / record |

**顺序不能乱。** 不关会话会占坑，下次报「并发满了」。

## 两种世界观

### 官方现成

列表接口返回名字 + ID。建会话时 ID 当作 `preset_id`。

### 自定义

写**世界是什么样**（不是具体剧情）：

- 好：`雨夜东京小巷，霓虹倒影，拉面摊蒸汽`
- 差：`第三分钟男主告白然后爆炸`（这是导播词，留给 prompt）

拍法：

| 选项 | 人话 |
|------|------|
| POV | 第一人称/跟着走 |
| Ambient | 固定氛围、小动作、少自己跑剧情。**数字人小幅度高稳定用这个** |
| Dramatic | 多人、台词、带一点故事 |

数字人要口型稳、动作不飘：先做一条 **locked-portrait seed**（人在正中、近景、镜头几乎不动、背景像一张静图、约 40 秒各种小闲着循环）。细节见 `SEED_VIDEO.md`。

## 预约状态

| 状态 | 人话 | 你该干嘛 |
|------|------|----------|
| PENDING | 排队中 | 等 |
| ACTIVE | 轮到你了 | **马上进 Session** |
| GENERATING | 已在生成 | 多半已有会话 |
| COMPLETED / EXPIRED | 过期 | 重新约 |

独占满了 → 改排队，或关掉旧会话再试。

## 进房后最少两句话

1. **开机**（`init_message`）— 等对方回「开始生成了」再认为真的有画  
2. **导播**（`prompt_message`）— 改剧情  

## 验收（非技术可勾）

1. 能否选中/自建一个世界观？  
2. 预约能否到 ACTIVE？  
3. 进房 5–15 秒内是否有动态画面？  
4. 发一句导播后画面是否有变化？  
5. 关掉后下次还能再约？  
6. （可选）结束后能否拿到 MP4？

## 时间预期

| 事 | 大概 |
|----|------|
| 建自定义世界 | 5–10 秒 |
| 预约 | 1 秒内 |
| 进房+开机到出画 | 5–10 秒 |
| 可玩窗口 | 约数分钟 |
